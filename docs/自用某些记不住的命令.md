docker desktop start或者直接启动docker桌面端


## 启动milvus
cd D:\milvus
docker compose -f compose-local.yml up -d --pull never


## 启动后端fastapi
cd D:\1pyproject\rag0\backend
python -m uvicorn api:app --host 127.0.0.1 --port 8000
或者约定用utf8编码：python -X utf8 -m uvicorn api:app --host 127.0.0.1 --port 8000


## 启动前端st
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501 -reload
或者指定端口且utf8编码：
python -X utf8 -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501




## 启动pgadmin
ps中：
docker compose -p rag-memory --env-file "D:\1pyproject\rag0\backend\.env" -f "D:\1pyproject\rag0\infra\postgres\compose.yml" up -d

前端页面的用户、密码：用backend\.env下的
PGADMIN_DEFAULT_EMAIL=admin@example.com
PGADMIN_DEFAULT_PASSWORD=ps_pg


##启动celery
python -m celery -A app.core.celery_app:celery_app worker --pool=solo --loglevel=info

## 进入pgsql
docker exec -it rag-memory-postgres-1 sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB"'
