# RAG 项目功能清单

更新时间：2026-10-19

## 本期实施范围：个人知识库基础闭环

- 必做：知识库按用户隔离；上传、更新、删除及检索校验归属。
- 必做：单文件上传更新、SHA-256 内容不变跳过、删除及基础结果反馈。
- 必做：PostgreSQL 文档归属与导入记录、数据目录配置、针对性权限和更新删除验证。
- 历史共享资料不自动归入任何用户，明确归属后重新上传；不执行破坏性全量重建。
- 后续增强：版本恢复、异步任务、目录监听、对账与块级优化，详见各分类。
- 本节记录范围，不代表已实现或已验证；完成状态以各项说明和实际验证为准。
- 本轮基础实现已接入，8 项离线测试通过；数据库迁移尚未执行，真实 PostgreSQL/Milvus 和页面端到端验证待完成。使用方式见 [个人知识库基础功能.md](个人知识库基础功能.md)。


## 1. 用户与权限

### 已有

- 注册、登录、退出及 Bearer 令牌身份认证。
- 密码使用加盐 scrypt 哈希保存，不存明文密码。
- 登录令牌有效期 24 小时，数据库仅保存令牌哈希；退出时撤销当前令牌。
- 后端从登录令牌取得用户 ID，替代客户端传入的身份。
- 会话、长期记忆保留用户归属检查；问答和上传接口要求登录。
- 前端提供注册、登录、退出入口及请求返回 401 后的登录状态清理。
- 用户信息与登录令牌保存到 PostgreSQL。
- 旧的手动用户 ID 入口已停用。
- 个人文档保存用户归属、隔离存储；上传、更新和删除限定当前登录用户，API 检索按授权有效来源过滤。

### 待验证

- 不同账号的会话、消息和长期记忆隔离专项验证。
- 令牌过期、伪造令牌及退出后旧令牌失效的专项验证。

### 未做

- 项目级或多人共享知识库权限；未来任务查询和重试的归属校验。
- 历史共享资料明确归属并迁移，未分配资料不向个人知识库开放检索。
- 用户数据保留、账号删除及关联数据清理规则。
- 修改密码、密码找回、登录限流与过期令牌定期清理。

## 2. 会话与历史记录

### 已有

- 新建会话、显示会话列表、切换会话及恢复历史消息。
- PostgreSQL 持久保存用户、会话、成功问答及引用来源。
- 成功问答的问题、答案和来源同事务保存。
- 首轮成功问答生成会话标题。
- 后端消息读取支持分页参数，并用于上下文构建。
- 会话重命名。
- 会话删除接口及页面确认入口已接入；删除会话、消息和摘要，保留长期记忆。
- 会话 Markdown 导出接口与页面下载入口；包含全部已保存消息、时间、状态及引用来源，不受页面 100 条限制。
### 待验证

- 自动标题专项回归。
- 会话删除及数据库级联删除效果（本次按用户要求未运行测试）。
- 会话导出及下载效果（按用户要求未验证）。

### 未做


- 页面加载更多历史消息。
- 完整记录失败、中断及达到尝试上限的请求。
- 请求幂等、同会话并发顺序控制。

## 3. 资料上传与解析

### 已有

- 页面上传 UTF-8 Markdown，最大 5 MiB。
- 校验空文件、无正文文件、编码和非法路径形式。
- 当前用户同名同内容文件跳过；同名不同内容更新；不同用户同名文件独立。
- 按文档 ID 更新正文、删除文档，页面提供同名上传更新和带确认的最小删除入口。
- 删除先标记不可检索，再清理磁盘和向量，失败可重复删除；历史聊天引用不随之删除。
- 按 Markdown 标题组织正文，保留标题路径、文件名及来源等信息。
- 长文本按需语义切分，再按 UTF-8 字节长度补充分块。
- 历史全量解析基线：430 个文件、2177 个块，长度检查已有通过记录。

### 待验证

- 上传后的实际块数、检索结果及端到端效果。
- 更多超长章节、非标准标题资料的解析表现。

### 未做

- 自动清理首次上传失败及历史清理失败留下的孤立文件和向量。
- 更多文件格式支持不在当前计划中；当前只列 Markdown 能力。

### 暂缓

- 完整知识库管理页面（已提供删除所需的最小文档选择列表）。

## 4. 文档入库与同步

### 已有

- 全量批量入库，采用解析、写入双进程与有界队列。
- 主进程检查子进程退出状态，异常或中断时清理仍运行的子进程。
- 文件级增量导入：扫描目录，通过 SHA-256 判断内容变化。
- SQLite 清单保存哈希、块数、处理状态、错误及更新时间。
- 旧命令行单文件导入保留；个人上传使用独立服务，不扫描整个目录。
- 未变化且成功的文件跳过；失败或处理中记录可在再次执行时处理。
- 旧命令行修改文件仍先删除旧向量再写入；个人上传改为不可变快照写入、校验块数后发布有效来源，再尽力清理旧来源。
- PostgreSQL 个人文档清单保存归属、哈希、有效来源、块数及状态；旧 SQLite 清单未自动迁移。
- 当前用户写入以事务级 advisory lock 串行，保留进程内全局锁；细粒度并发仍待优化。
- 历史全量入库及分页核对已有 430 文件、2177 块的运行记录；上传后总量需另行核对。

### 待验证

- 新增、修改、重复执行无重复块等专项场景。
- 删除旧向量后写入失败的恢复表现。
- 子进程异常、写入故障及资源占用。

### 未做

- PostgreSQL 持久入库任务表与独立 worker。
- 上传返回任务 ID，页面查询排队、处理、成功或失败状态。
- 自动重试、处理超时、租约及服务重启恢复。
- 目录新增、修改、重命名、删除事件监听。
- 同文件事件合并、防抖、写入稳定检测及事件任务幂等。
- 启动和定期对账，补偿漏事件。
- 磁盘删除自动同步向量删除。
- SQLite 清单迁移到 PostgreSQL。
- 完整历史版本管理、回滚、块指纹校验和旧版本清理补偿。
- 跨库失败补偿、多 worker 同文件互斥及版本乱序处理。
- 全量重建后清单失效的自动处理。
- 常规扫描按大小、修改时间预筛选，必要时分块计算 SHA-256。
- 确定性块键及幂等重放；解析规则、Embedding 模型变更纳入处理配置指纹。
- 自动目录同步时，目录不可访问不直接判定全部文件已删除。
- 块级差异比较及 Embedding 复用（后续性能优化）。

旧命令行更新仍存在旧资料丢失风险。个人更新的候选来源仅发布后才可检索，但跨库失败仍可能留下孤立数据；PostgreSQL 与 Milvus 没有共同事务。文档异步队列暂不接入。

### 暂缓

- 导入清单查看脚本和页面。

## 5. 检索与联网搜索

### 已有

- 本地 BGE 语义向量检索、BM25 关键词检索与 RRF 排名融合。
- Milvus 存储文档块及检索所需信息。
- 过滤正文类别，逐篇判断文档相关性。
- 根据问题选择本地知识库或 Tavily 联网搜索。
- 本地资料不相关时改写问题、重新检索，达到条件后转联网。
- 联网结果统一为 Document，保存网页标题、地址及来源类型。
- API 本地搜索使用当前用户的有效来源白名单，在搜索前排除他人、未发布及删除中资料；缺少用户身份时不回退共享语料。

### 未做或待完善

- 优化召回数量、融合参数、过滤策略及干扰文档处理。
- 真正的模型 reranker；当前 RRF 是排名融合。
- 相关性评分批处理、缓存及调用成本优化。
- 联网资料可靠性处理。
- 大规模授权来源过滤优化和跨进程检索版本快照。
- 引入检索缓存时，缓存键包含用户、知识库及修订号，发布或删除后失效。

### 暂缓

- 页面展示召回、过滤数量及各阶段耗时等检索详情。

## 6. 问答生成与引用

### 已有

- FastAPI 问答接口与页面聊天入口。
- LangGraph 编排路由、检索、评分、改写、生成和联网回退。
- 区分用户原始问题与检索改写问题。
- 根据资料生成回答，检查资料支持程度和是否解决原问题。
- 每轮最多生成 3 次，达到上限后结束并给出失败说明。
- 本地和联网资料统一编号，回答提示引用编号，页面可展开来源。
- 部分真实问答及重试、第三次成功、改写重检、联网回退模拟分支已有通过记录。

### 待验证

- 全量语料下完整问答回归。
- 引用编号范围、逐句引用、数值边界及排他性措辞准确性。
- 资料不足边界测试此前被跳过，仍待验证。

### 未做或待完善

- 稳定 chunk 标识及更精确的引用追溯。
- 失败、中断、重试上限等情况的完整记录与恢复体验。
- 资料不足、联网回退和失败回复的进一步完善。
- 流式回答，以及评分失败重试时的草稿展示策略，尚未选择实施。

## 7. 短期上下文与历史摘要

### 已有

- 多轮上下文用于指代消解，基本追问效果已有用户确认。
- 按页读取完整问答，近期历史按约 4000 Token 估算预算选取。
- 增量压缩旧消息，保留原始消息，不因摘要删除原文。
- 旧消息约 1000 Token 或近期历史为空时尝试摘要。
- 每次最多处理一批：最多 100 条，新增消息预算约 6000 Token，摘要上限约 1200 Token。
- 使用 tiktoken 通用编码估算，不是 Qwen 精确计数。

### 待验证

- 摘要实际质量、覆盖边界、重复处理、漂移及失败恢复。
- 早期无摘要版本的 7 项离线检查不能代替当前摘要版本验证。
- 摘要相关迁移的实际部署状态。

### 未做（本阶段暂缓）

- 摘要后台化、超长单轮拆分及历史积压处理。
- 统一约束历史、摘要、资料和其他提示内容的上下文总预算。

## 8. 长期记忆

### 已有

- PostgreSQL 长期记忆模型和迁移文件。
- 保存、查询、删除 API，以及前端记忆面板。
- “记住：”显式保存回答偏好。
- 普通成功问答提交后，使用 BackgroundTasks 从本轮用户原话提取记忆。
- 每轮最多 3 条候选，自评置信度至少 0.85，依据需出现在原文。
- 完全相同内容去重。
- 回答偏好注入生成提示：从最近 50 条记忆中选择，总长度最多 2000 字符。
- fact 类型可保存，当前没有按问题检索并用于回答。

### 待验证

- 迁移部署、面板、自动提取、跨会话偏好及删除效果的完整专项验证。
- 模型自评置信度不代表实际准确率。

### 未做（本阶段暂缓）

- 修改记忆接口、自然语言“修改／忘掉”。
- 自动记忆开关、来源展示和错误记忆纠正。
- 语义去重、冲突更新及版本管理。
- 背景事实按问题检索，概况与详情分层读取。
- 持久提取任务、自动重试、重启恢复、限流与积压控制。

## 9. 页面交互与 API

### 已有

- Streamlit 聊天页面，包含用户选择、会话切换、历史展示、文件上传、来源展开和记忆面板。
- FastAPI 请求参数校验与 API 文档入口。
- 基础 `/health` 接口，仅表示 API 进程已启动。
- 上传与问答共用进程内锁。
- 个人文档列表、更新和删除 API，以及页面同名更新反馈、确认删除和失败重试提示。

### 未做或待完善

- 上传后台处理进度与失败重试交互。
- 长消息、记忆列表的加载更多能力。
- 同会话、同文件的细粒度并发控制；当前锁不能覆盖多个进程。
- 后续异步任务查询、重试接口及归属校验。
- 同文档串行、不同文档并行；版本及执行令牌校验，防止旧任务覆盖新版本。
- 检查 PostgreSQL、Milvus 和模型依赖是否可用的就绪接口。

## 12. 当前不纳入实施范围的扩展

- 代码执行沙箱：引入代码执行工具后再设计。

## 如何使用这份清单

先从会话管理、资料更新删除、问答失败反馈等基础体验中选择一项补齐；需要解决入库中断和恢复时，再推进持久任务与 worker。本文用于盘点功能，不调整 `process.md` 的既有计划，也不自动启动暂缓事项。
