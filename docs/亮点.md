rag_agent
instruction：用户可实现登录并导入md文档，RAG采用混合向量检索，多轮问答，可联网，来源引用。
tech：Python、LangChain、LangGraph、Milvus、BGE、BM25、通义千问的API、FastAPI、Streamlit、SQLite、Tavily、Docker。

文件切分是先md加载器切分然后按照标题切分
1：语义关键词混合检索：基于BGE语义向量建立HNSW图索引检索和基于BM25关键词建立倒排索引daat-wand算法检索，最后通过RRF融合排名。
2:工具封装：基于 LangChain封装混合检索，集成Tavily检索工具。
3：工作流编排：基于langGraph实现本地查询路由、文档相关性判断、本地资料不足的问题改写、重检和联网回退。模拟测试生成重试上限、第三次成功、问题改写重检及联网回退等分支。
4：检索和生成效果评测：基于50道问题对比BM25、BGE与混合检索，混合方案Recall@5达0.82、MRR@5达0.83，较BM25分别提升14和11个百分点，RAGAS忠实度达0.87，平均端到端耗时2.66秒。
5：会话记忆：基于pgsql存储会话历史，短期记忆按照token预算使用近期会话+历史摘要（目标，约束，进展，代办），长期记忆自动整合（llm）从聊天提取稳定偏好、项目背景及确认事实，去重并整合，支持显式记忆操作如“记住／修改／忘掉”触发保存、更新或删除


6：文档增量入库：全量检测（待改进）

1：用户登录功能：基于 FastAPI 依赖注入实现用户认证，采用 scrypt 加盐密码哈希与 PostgreSQL 持久化 Bearer 令牌，支持注册、登录、退出及会话和记忆的用户归属校验。
